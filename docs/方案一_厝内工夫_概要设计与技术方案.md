## 1. 方案背景与目标硬件约束

### 1.1 核心软硬件环境定义
本项目选定现代 Web 主流方案，目标硬件为典型家庭闲置平板 **iPad mini 2**。该硬件与系统具备高度独特的参数特征：

| 硬件/系统参数 | 物理参数与系统环境 | 核心工效与架构约束 |
| :--- | :--- | :--- |
| **设备型号** | iPad mini 2 (2013年底发布，A1489/A1490) | 处理器为 Apple A7 (双核 1.3GHz 64位) |
| **运行内存** | **1GB LPDDR3** (极小运行内存) | **内存红线**：Safari 网页内存超过 100MB~150MB 会触发 iOS Jetsam 机制强制白屏刷新。必须选用轻量无泄漏架构。 |

## 2. “潮音为主·极简无扰”认知工效原则（Zero-Distraction Principle）

文盲高龄老人的大脑工作记忆容量极低，信息过载会导致认知通道堵塞与抗拒。因此本系统确立**极简去噪三原则**：

### 2.1 提示语言“字数减法”
- **彻底消灭口号与说教长句**：绝不出现“🗣️ 揭阳潮汕话：冲茶食茶个...”、“👉 轮到您了！摸一摸大字，倒满金茶水”、“✨ 记牢了！真乖！茶字会认了！”等冗长干扰。
- **全界面超精炼文本**：
  - 主场景底部提示：**`👆 点茶具识字`** / **`👆 点厨具学字`**（仅 5 字）；
  - 学习大字标头：**`茶  dê⁵`** / **`刀  to¹`**（仅显示字与音标）；
  - 试写操作提示：**`点字倒茶`**（仅 4 字）；
  - 通关提示：**`✨ 学会了！`**（仅 3 字）。

### 2.2 默认发音“100% 潮汕母语”
- **点击物件后，默认仅播放纯正潮汕原声音频切片**（如 `to1.mp3`、`kam1.mp3`、`te5.mp3` 等），随后自然静默启动慢速笔画动画，绝不自动插播任何普通话语音打断老人家思考。
- **普通话对照退为兜底选择**：仅当老人或儿女主动轻触底部 **`[🗣️ 国语]`** 按钮时，系统才极简读出“刀，dāo”，不带任何废话。

## 3. “甘”字标准笔顺与拓扑修正

针对“甘”字笔顺的国家规范（《现代汉语通用字笔顺规范》）与楷体字骨对齐问题，完成严格修正：

```
         (300,180)        (500,170)
             │                │
(180,265) ───┼────────────────┼─── (620,250)    ← 1. 一横 (首长横，居中舒展微仰)
             │                │
             ├── (300,440) ───┤ (500,435)       ← 4. 四横 (中横，两端紧接竖画不出头)
             │                │
(270,660) ───┴────────────────┴─── (530,655)    ← 5. 五横 (底横，封口托底微出头)
         (300,660)        (500,660)
             ↑                ↑
         2. 二竖 (左竖)    3. 三竖 (右竖)
```

- **正确规范笔画顺序（横 ➔ 竖 ➔ 竖 ➔ 横 ➔ 横）**：
  1. **一横**：顶部首长横（`M 180,265 L 620,250`，长 440px，贯穿左右，起笔平稳微仰）；
  2. **二竖**：左侧坚挺长竖（`M 300,180 L 300,660`，长 480px，上端出头 85px，垂直通达底部）；
  3. **三竖**：右侧坚挺长竖（`M 500,170 L 500,660`，长 490px，上端出头 95px，右肩微耸对称直通底部）；
  4. **四横**：中间连接短横（`M 300,440 L 500,435`，长 200px，两端紧接左右两竖，框内不出头）；
  5. **五横**：底部托底封口横（`M 270,660 L 530,655`，长 260px，左右微展各 30px 托底收敛）。

## 5. 高可扩展架构重构与运行指引

系统采用分层可插拔架构，支持平滑扩充任意生活实景：

### 5.1 模块拓扑结构
```
src
├── types
│   └── literacy.ts                 # 领域标准定义 (StrokeItem, WordItem, SceneConfig 等)
├── data
│   ├── scenes
│   │   ├── teaTableScene.ts        # 场景一：“厝内工夫” (茶、水、杯、火、叶、甘)
│   │   └── kitchenScene.ts         # 场景二：“灶下炊事” (刀、切、米、鼎、炊、炒、碗)
│   └── index.ts                    # 场景全局注册中心 (SCENES 字典与快速查找)
├── services
│   ├── audioService.ts             # Web Audio 静默解锁与潮声音频切片播放
│   └── teaWordsData.ts             # 向后兼容转发层
├── components
│   ├── common
│   │   └── SceneSelector.vue       # 顶层场景切换胶囊栏
│   ├── scenes
│   │   ├── TeaTableScene.vue       # 场景一拟物表现层：工夫茶桌实景
│   │   └── KitchenScene.vue        # 场景二拟物表现层：传统灶台实景（7大厨具与动作）
│   └── literacy
│       └── LiteracyFocusView.vue   # 完全独立通用的“大字具身识字核心引擎”
└── App.vue                         # 顶层 4:3 视口锁定与“实景态/识字态”调度总控
```

### 5.2 运行与体验步骤
1. **启动服务**：
   ```bash
   npm run dev
   ```
2. **测试体验**：
   - 浏览器打开 `http://localhost:3000`（按 `F12` 切换为移动设备模式）；
   - **场景切换**：点击左上角胶囊按钮 `🍳 灶下炊事`，进入传统柴火大灶实景；
   - **点按厨具与动作学字**：
     - 点击木砧板菜刀 ➔ 学 **`刀`**（超简单 2 画快速建立老人自信）；
     - 点击翻炒铁铲 ➔ 学 **`炒`**（体验热鼎炒菜动作）；
     - 点击竹编高蒸笼 ➔ 学 **`炊`**（潮汕灵魂炊事动作）；
     - 点击黑铁大锅 ➔ 学 **`鼎`**（潮汕灶具核心）；
     - 每一字均自动播放正宗潮音母语，金色毛笔 3 倍慢速描画，老人轻点即可灌满热汤水通关！
