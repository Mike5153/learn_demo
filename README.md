# 潮汕老人家具身识字系统 (Chaoshan Literacy App)

面向潮汕高龄文盲、半文盲老人量身打造的平板端具身识字交互系统。

---

## 🌟 核心特色

1. **生活实景具身认知**：
   - 包含**“厝内工夫”**（工夫茶桌实景）与**“灶下炊事”**（厨房烹煮实景）两大生活主题；
   - 从老人摸了一辈子的茶具（冲罐、砂铫、若琛瓯）和厨具（菜刀、铁鼎、米缸）切入，见物听乡音，由物识字形。
2. **潮汕方言本土原声**：
   - 内置 13 个代表性汉字的原汁原味本土潮汕话（揭阳音）录音切片；
   - 方言母语唤醒认知 ➔ 书法笔顺动画演示 ➔ 手写磁吸练字 ➔ 慢速标准普通话对照。
3. **适老化高容错手写引擎**：
   - 自研几何拓扑降采样算法（$N=16$ 等距点归一化）；
   - 主向量夹角防倒笔校验（逆向倒笔友好提示）；
   - 55% 宽松容错打分，端点宽松磁吸，手指颤抖亦能轻松完成书写。
4. **低配老旧平板（iPad mini 2 / iOS 12）深度兼容**：
   - 针对 iOS 12.5.7 (Safari 12) 自动化 Legacy 编译与核心 Polyfill 注入；
   - 内存占用严格压制在 80MB 以内，零大型 UI 库，无 WebGL 内存负担；
   - 纯 Web Audio 实时硬件合成五音和弦（宫商角徵羽）与运笔沙沙声，零加载延迟。

---

## 🛠️ 技术栈

- **框架底座**：Vue 3.4 (Composition API, `<script setup lang="ts">`)
- **语言标准**：TypeScript 5.5
- **工程构建**：Vite 5.4 + `@vitejs/plugin-legacy` + `terser`
- **图形与交互**：SVG 2.0 (800×800 虚拟空间) + HTML5 Canvas 2D
- **音频系统**：Web Audio API (Oscillator/Gain 实时波形合成) + HTML5 Audio + Web Speech API

---

## 🚀 快速启动

### 1. 安装依赖
```bash
npm install
```

### 2. 启动开发服务器（支持同一局域网 iPad 直接访问调试）
```bash
npm run dev
```
> 控制台将输出局域网 IP（例如 `http://192.168.x.x:3000`），老人家手持 iPad mini 2 连入同一 Wi-Fi 即可在 Safari 直接打开使用。

### 3. 生产打包
```bash
npm run build
```
